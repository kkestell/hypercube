## F1. Failed restart tests leave detached holders running

Medium · Resources · Fixed · `internal/session/fixture_test.go:52`

Restart tests detach a runtime before checking offline output and attaching a
replacement. If a check fails in between, the registered `Quit` returns
immediately because that runtime is detached. Its holders survive fixture
removal and retain inherited test output descriptors, potentially delaying suite
completion as well as leaking processes. The implementation session observed
this during a failed run; the lifecycle trace confirms the missing owner.

### Fix

The fixture now stops and removes holders remaining under its own database's
`run` directory. Cleanup registration places this after every runtime cleanup
and before database closure and directory removal. It does not restore sessions
or launch replacement processes. Verified the resulting cleanup order and
state-directory scope by inspection.
