# Archive sessions

## Goal

Archive a top-level session and its family after the same Git checks as Delete. Stop the family and remove its managed worktrees and branches while retaining its conversations. Hide the family from the sidebar; make it available read-only from Settings and search, and allow its deletion from Settings.

## Decisions

The least costly complete implementation uses `Ended` on a top-level session to mean archived, and `Ended` on each child for the existing read-only behavior. A top-level ended session does not exist today, so this needs no new saved field or migration. Keep the family in the existing snapshot: selection and search need those rows even when the sidebar does not show them. Settings can derive its archive list from the same data. No separate archive store, search index, or cleanup path is needed.

Reuse Delete's preflight and cleanup for the family. Preflight must finish before stopping or changing anything, and report the same dirty or unmerged worktree failures. Once preflight passes, cleanup may still fail if work changes before removal, as with Delete. Preserve the stopped family and its chats on such a failure, record each child's completed cleanup using `Ended`, and leave the top-level session unarchived until its own cleanup succeeds, so the operation can be retried. Existing ended children and external child directories remain untouched. Deleting a completed archive must not attempt to remove its already-removed worktree or branch, including if a branch with the same name was subsequently created.

## Implementation plan

1. In `internal/session/sessions.go`, factor the existing top-level Delete preflight and worktree cleanup into a shared family operation, preserving Delete's behavior. Add Archive for top-level sessions only. After preflight, prevent concurrent starts, stop agents and shells, and persist the stopped state. For Archive, retain rows and transcripts, mark each cleaned child ended and drop its queued messages, then mark the root ended and drop its queued messages after its cleanup succeeds. Clear attention as for stopped and ended sessions. On a cleanup error retain the remaining resources and rows for retry. Guard Start against ended roots, including under the runtime lock. Ensure Delete and DeleteWorkspace can delete archives without rechecking or removing completed resources. Keep `internal/session/children.go`'s existing end behavior aligned with the shared cleanup only where the existing code naturally permits it; do not add a second worktree removal implementation.
2. Add the archive action in `internal/ui/actions.go`. In `internal/ui/web/sessions/session-actions.js` and `internal/ui/web/sidebar/sidebar-menus.js`, offer Archive for top-level sessions and send the action, presenting failures through the existing action handling. Filter ended top-level families only in `internal/ui/web/sidebar/sidebar.jsx`; keep `internal/ui/snapshot.go` and `internal/ui/web/sessions/selection.js` able to find and select archived parents and children. Ensure selecting an archived family member never starts it and the existing ended composer disables sending. Preserve access to each child's chat through search and the archived family's view.
3. **Depends on the Settings branch merging first:** add an Archived Sessions section to its dialog under `internal/ui/web/app/`, using the existing workspace snapshot to list archived top-level sessions with workspace identification. Open selects the family read-only, with a way to select its children's chats; Delete uses the existing session deletion confirmation and action, with accurate family-chat wording. Adjust the exact Settings files after that branch merges. Check that selection from Settings or search closes the dialog and returns focus appropriately.
4. Keep `internal/store/search.go` searching all saved rows; update only if integration reveals filtering elsewhere. Update `docs/usage.md` for archive, read-only access, search, cleanup checks, and deletion.

Cover checkout sessions, worktree sessions, already-ended children and external child directories. Exercise cleanup failure after preflight and retry, and deletion of an archive without touching a subsequently recreated branch. Verify persistence across runtime restart and workspace deletion.
