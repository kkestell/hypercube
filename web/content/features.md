Hypercube is a macOS and Linux app for coordinating local coding agents.

| What you can do | Learn more |
| --- | --- |
| Run Claude Code, OpenCode, and Pi with their own models and credentials. | [Harness differences](docs/harness-support.md) |
| Send prompts, images, corrections, and answers to questions or approvals. | [Manage sessions](docs/usage.md) |
| Delegate a bounded task or request an independent review. | [Work with a team](docs/teamwork.md) |
| Share a checkout or isolate edits in separate Git worktrees. | [Sessions and working copies](docs/introduction.md) |
| Browse files, search text, inspect diffs, and use a session terminal. | [Review files and changes](docs/review-changes.md) |
| Keep work running after the app closes and return to saved conversations. | [What keeps running](docs/lifecycle.md) |
| Arrange split panes, change appearance, and navigate with shortcuts. | [Interface reference](docs/interface.md) |

Start with [installation](docs/installation.md) and the
[first-session walkthrough](docs/getting-started.md).
