# Linux bundle

## Plan

`agents/plans/2026-11-06-015-linux-bundle.md`

## Summary

`make bundle`, `make build`, and `make release` work on Linux. The `Makefile`
includes `make/macos.mk` or `make/linux.mk`; `scripts/release` has a function
per platform; `desktop/` gained the `.desktop` file and `desktopName`;
`scripts/linux/test-bundle`, `make linux-test`, and a `linux-test` CI job
check the bundle. `desktop-file-utils` is in the image. `agents/development.md`
and `agents/architecture.md` describe the changes.

## Departures from the plan

- None in approach. `bin/release/` on Linux also keeps the unpacked
  `Hypercube/` directory beside the archive and `SHA256SUMS`, as macOS keeps
  `Hypercube.app`.
- The macOS arm64 check in `scripts/release` moved into `package_macos` and
  reads `go env GOARCH`; it runs after `rm -rf bin/release`, not before.

## Decisions

- `test-bundle` reads `desktopName` with `node -p`, because the packager leaves
  `package.json` pretty-printed on Linux while `plutil` compacts it on macOS.
- `test-bundle` picks its backend port at random between 20000 and 39999.

## Checks run

- `scripts/linux/run scripts/linux/test-bundle` — passed (arm64).
- Plugin removed from `PLUGINS` — failed with "hypercube-harness-pi is not an
  executable file". `desktopName` changed — failed with "desktopName in
  package.json is not com.github.kkestell.hypercube.desktop". Both restored.
- Release in the container (`git init`, commit, tag `v0.0.0-beta.1`,
  `make release`) — `bin/release/` held `Hypercube-v0.0.0-beta.1-linux-arm64.tar.gz`
  and `SHA256SUMS`; `shasum -a 256 -c` passed; the extracted
  `Hypercube/hypercube version` printed `Hypercube v0.0.0-beta.1 (<commit>)`.
- `scripts/linux/run` (`make check`) — passed.
- macOS `make bundle` and `make build`, compared with a bundle built before the
  change by `diff -rq --no-dereference`: only `Resources/app/package.json`
  (`desktopName` added, key order from the packager), the `Hypercube Desktop`
  executable (32 bytes of its ad hoc code signature, which hashes
  `package.json`), and `_CodeSignature/CodeResources` differed.
  `codesign --verify --deep --strict` passed.
- `scripts/release` on the dirty checkout with a tag at HEAD stopped with
  "commit or remove checkout changes before packaging".
- macOS release path, on a clean copy committed and tagged `v0.0.0-beta.1` in a
  temporary directory: `scripts/release` produced
  `Hypercube-v0.0.0-beta.1-macos-arm64.zip` and a passing `SHA256SUMS`.
