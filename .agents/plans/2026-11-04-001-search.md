# Search session files

## Goal

Search the shown session's files by case-insensitive plain text and open a matching line.

## Decisions

Reuse the Quick Open listing on the server, scan text files with the standard library, and cap results at 1,000 matching lines. The Search panel requests results as the query changes and uses the existing requested-file opening path. No additional search modes are required.

## Implementation plan

- Extract the shared file listing in `internal/ui/mention_files.go`; add a search endpoint and test it through HTTP.
- Add the Search tab, query, grouped results, and keyboard shortcut in `internal/ui/web`; test user interactions.
- Document the search and its limit in `docs/usage.md`.
