# Settings for saved tool choices

## Goal

Show saved Always-allow choices in Settings and let the user remove them, including for running sessions.

## Decisions

Approvals already consult the database for each request, so deleting a grant is sufficient for running sessions. List grants with their session titles directly from the store and use a small HTTP endpoint for listing and removal. Use the existing shortcut and modal paths, with the App menu entry inserted at its standard position.

## Implementation plan

- Add store queries to list and delete grants, and expose them through UI routes.
- Add Settings to the shortcut table and native App menu, and open a dialog from the shortcut or sidebar gear.
- Display each tool, harness, and scope in a simple list with a remove button; refresh after removal and show an empty line when appropriate.
- Cover grant removal and Settings interaction through public entry points, and update `docs/usage.md`.
- Regenerate UI assets and run the required checks.
